# 🎨 Imágenes del Plugin NGSI Woo Carousel

## 📁 Archivos de imagen incluidos

### Iconos del Plugin
- **`assets/media/icon.svg`** - Icono SVG del plugin (128x128px)
- **`assets/media/producto.png`** - Imagen por defecto para productos sin imagen

### Banner y Marketing
- **`assets/media/banner.svg`** - Banner para GitHub (1200x400px)
- **`assets/media/generate-icon.php`** - Generador de icono PNG (opcional)

## 🎯 Uso de las imágenes

### Icono del Plugin
El icono SVG se muestra en:
- ✅ **Panel de administración** de WordPress
- ✅ **Header del plugin** en la página de configuración
- ✅ **Lista de plugins** en WordPress Admin
- ✅ **Repositorio de GitHub**

### Imagen por defecto
La imagen `producto.png` se usa cuando:
- ✅ **Producto sin imagen destacada**
- ✅ **Error al cargar imagen del producto**
- ✅ **Fallback** en caso de problemas de permisos

### Banner de GitHub
El banner SVG se muestra en:
- ✅ **README.md** del repositorio
- ✅ **Página principal** de GitHub
- ✅ **Releases** de GitHub

## 🎨 Diseño de las imágenes

### Paleta de colores
- **Primario**: #667eea (Azul gradiente)
- **Secundario**: #764ba2 (Púrpura gradiente)
- **Acentos**: #ffd700 (Dorado), #ff6b35 (Naranja), #2c3e50 (Azul oscuro), #27ae60 (Verde)
- **Texto**: #ffffff (Blanco)

### Elementos del diseño
- **Carrusel base**: Rectángulo blanco con bordes redondeados
- **Tarjetas de productos**: Rectángulos de colores con bordes redondeados
- **Flechas de navegación**: Triángulos blancos
- **Puntos de paginación**: Círculos pequeños
- **Texto**: Tipografía Arial con diferentes pesos

## 🔧 Personalización

### Cambiar el icono del plugin
1. Reemplaza `assets/media/icon.svg`
2. Mantén las dimensiones 128x128px
3. Usa formato SVG para mejor calidad

### Cambiar la imagen por defecto
1. Reemplaza `assets/media/producto.png`
2. Recomendado: 300x200px
3. Formato PNG con transparencia

### Cambiar el banner
1. Reemplaza `assets/media/banner.svg`
2. Mantén las dimensiones 1200x400px
3. Usa formato SVG para escalabilidad
